# 언어별 주석 규칙

공통 작성 기준은 `~/.codex/AGENTS.md`의 §코드 주석을 따르고, 작업 대상 언어의 형식을 함께 적용한다.

## Go

- doc comment는 한국어에서도 식별자를 맨 앞에 둔 `// Name ...` 형태로 쓴다. 예: `// Role은 …`, `// Package llm은 …`.
- struct 필드, `const`·`var` 블록 안 개별 항목, 지역 선언의 주석은 식별자 접두어 없이 설명으로 시작할 수 있다.
- 프로젝트 lint가 식별자 접두어를 요구하면 그 설정을 따른다.

## Rust

- 모듈·크레이트 문서는 해당 파일 맨 위 `//!`, 항목 문서는 `///`, 그 밖의 주석은 `//`로 쓴다.
- 문서화 주석의 첫 줄은 rustdoc 목록에 혼자 보이므로 한 문장 요약으로 쓴다.
- 공개 함수가 `Result`를 돌려주면 `# Errors`, panic할 수 있으면 `# Panics`, `unsafe fn`이면 `# Safety` 절에 그 조건을 적는다.
- 다른 코드 항목은 `` [`Name`] `` intra-doc link로 가리킨다.
