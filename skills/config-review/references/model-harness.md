# 모델·하네스 적합성
이 기준은 모델 역량이나 하네스를 근거로 행동 지침을 없애는 판단에 적용한다.
같은 문서의 반복을 합치거나 동일 소비자가 읽는 권위 문서로 중복을 모으는 편집은 구조 기준으로 의미·로딩 보존을 확인한다.

- 감사 대상 지침의 소비 주체와 모델, 호출 경로, 로딩 시점을 확인하고 `~/.codex/AGENTS.md`와 프로젝트 `AGENTS.md`, 선택된 `SKILL.md`, agent 설정, 호출 메시지와
  확인 가능한 시스템·developer 하네스 중 같은 실행에 실제로 들어오는 로딩 범위를 기록한다. 공식 지원 범위와 현재 실행에서 관찰한 범위를
  구분하며 한 소비 주체의 관찰을 다른 main이나 subagent에 일반화하지 않는다.
- 후보 유형은 사용자 정책·역할 계약, 하네스 중복 후보, 모델 역량 보상형 후보로 구분한다. 정책·계약형 지침은 모델이 스스로 같은 행동을
  수행할 수 있다는 이유만으로 역량 보상형 후보로 분류하지 않는다.
- 하네스 중복 후보는 같은 소비 주체와 같은 로딩 범위에서 하네스가 같은 의미와 강도로 동일 행동을 실제로 강제할 때만 성립한다.
  더 좁거나 강한 로컬 예외, 적용 시점이 다른 규칙, 하네스를 공유하지 않는 agent용 규칙은 중복으로 판정하지 않는다.
- 모델 역량 보상형 후보는 그 지침이 막던 기존 실패 가설을 Git 이력, 실제 세션, 기존 이슈나 사용자 근거로 명시한다. 실패 가설을
  복원할 수 없으면 추정임을 표시하고 축소 근거로 확정하지 않는다.
- 축소·제거 판단에는 후보 행동을 직접 드러내는 비파괴 대표 작업과 사전에 정한 관찰 가능한 기대 결과가 필요하다. 가능한 경우 같은
  모델·추론 수준·하네스·도구·권한·입력을 유지하고 후보 지침의 포함 여부만 바꾼 비교 결과를 사용한다. 동일 조건의 기존 실행 근거는
  사용할 수 있지만 조건이 다르거나 기대 행동을 검증하지 못하면 대표 작업 근거로 일반화하지 않는다.
- 실제 로딩과 대표 작업 비교가 제거 안전성을 뒷받침하면 `축소/제거 후보`, 근거가 부족하면 `검증 필요`로 보고하고 해당 행동 지침을 유지한다.
  정적 문구나 모델의 일반 역량만으로 행동 지침의 제거를 확정하지 않는다.

## 발견 사항 보고
- 소비 주체, 실제 로딩 범위, 후보 유형, 기존 실패 가설, 대표 작업·기대 결과, 비교 결과와
  `유지`·`축소/제거 후보`·`검증 필요` 처분을 포함한다.
- 실제 실행이나 하네스를 확인하지 못한 부분은 미확인으로 표시한다. 정적 검토 통과를 대표 작업 통과로 보고하지 않는다.
