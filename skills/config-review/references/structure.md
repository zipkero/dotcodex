# 설정 구조 감사 기준

## 역할과 호출
- main·analyzer·worker·verifier와 각 skill의 입력, 권한, 중단, 반환과 최종 판정 소유가 일치하는지 확인한다.
- agent 모델·추론·sandbox·fork 조건과 호출 실패 처리, 참조 경로가 실제 호출 계약과 맞는지 확인한다.
- 전역 흐름은 `AGENTS.md`, 단계 실행은 해당 skill, agent 실행 성격은 agent 설정이 소유하는지 확인한다.

## 문서와 상태
- Per-Request와 Phased 진입, 단계 순서, 선행 승인, 재시도, 상태 전환과 인수인계가 끊김 없이 이어지는지 확인한다.
- 다음 역할이 승인된 선행 문서와 관련 원본만으로 자기 작업을 시작할 수 있는지 확인한다.
- analyzer patch·전체 후보와 승인 상태가 의미·의존 관계에 따라 독립적으로 처리되는지 확인한다.

## 중복과 참조
- 함께 로드되는 지침이 같은 판단 기준을 반복 정의하거나 다른 역할의 권한을 다시 정의하는지 확인한다.
- 문장의 해석에 따라 실행 주체·변경 범위·승인 조건이 달라지는 표현을 찾는다.
- 삭제·이동한 파일의 참조, README 구조 설명, frontmatter·openai.yaml·TOML과 Git 추적 범위를 확인한다.
